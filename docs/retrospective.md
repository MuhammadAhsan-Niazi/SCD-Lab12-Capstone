# Sprint 1 Retrospective

## What went well
- Test-first commits kept each story small and verifiable.
- Acceptance criteria turned directly into test names, so "done" was objective.

## What did not go well
- Discount rounding was ambiguous until the stand-up; the acceptance criteria did not state the rounding order.
- Pull requests were self-reviewed; a second reviewer would have caught the missing validation for negative prices in the first draft.

## One specific, measurable process change for Sprint 2
**Every story's acceptance criteria must state the exact rounding and order of operations, and every pull request
must have at least one reviewer other than its author before merge. Target: 100% of Sprint 2 PRs with a second reviewer,
verified by counting approvals on GitHub at the sprint review.**
